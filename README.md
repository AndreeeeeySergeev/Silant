# Электронная сервисная книжка «Мой Силант»

Веб-приложение электронной сервисной книжки для хранения информации о строительной технике, техническом обслуживании и рекламациях.

## Технологии

* Python
* Django
* PostgreSQL
* HTML
* CSS
* JavaScript

## Структура проекта

Основное Django-приложение:

```text
core
```

Конфигурация проекта:

```text
config
```

Шаблоны находятся в:

```text
templates/
```

Статические файлы:

```text
static/
```

CSS-файлы разделены по страницам:

```text
static/
└── css/
    ├── style.css
    ├── home.css
    ├── machines.css
    ├── maintenance.css
    ├── claim.css
    └── ...
```

Миграции приложения находятся в:

```text
core/migrations/
```

## Установка

Для запуска проекта требуется Python и PostgreSQL.

Создать виртуальное окружение:

```bash
python -m venv venv
```

Активировать виртуальное окружение.

Windows:

```bash
venv\Scripts\activate
```

Установить зависимости:

```bash
pip install -r requirements.txt
```

## Настройка PostgreSQL

В проекте используется база данных PostgreSQL с именем:

```text
silant
```

В `config/settings.py` указаны параметры подключения к базе данных.

При необходимости следует изменить параметры подключения к PostgreSQL под локальную конфигурацию.

## Восстановление базы данных

В проект вместе с исходным кодом предоставлен дамп базы данных:

```text
silant_dump.sql
```

Сначала необходимо создать базу данных:

```sql
CREATE DATABASE silant;
```

После создания базы данных необходимо восстановить дамп.

Для Windows/Linux с установленным PostgreSQL:

```bash
psql -U postgres -d silant < silant_dump.sql
```

После восстановления база будет содержать тестовые данные для проверки работы приложения.

## Миграции

Миграции Django находятся в приложении `core`.

При необходимости проверить состояние миграций:

```bash
python manage.py showmigrations
```

Если база создаётся с нуля без использования предоставленного дампа:

```bash
python manage.py migrate
```

При использовании предоставленного `silant_dump.sql` выполнять миграции повторно обычно не требуется.

## Запуск проекта

После установки зависимостей и восстановления базы данных выполнить:

```bash
python manage.py runserver
```

После запуска приложение будет доступно по адресу:

```text
http://127.0.0.1:8000/
```

## Основные разделы

### Главная страница

На главной странице можно выполнить поиск техники по заводскому номеру.

### Машины

Раздел содержит список зарегистрированной техники и подробную информацию о каждой машине.

### Техническое обслуживание

Раздел содержит информацию о проведённых технических обслуживаниях.

Предусмотрены:

* фильтрация по виду ТО;
* фильтрация по заводскому номеру машины;
* фильтрация по сервисной компании;
* сортировка по дате;
* сортировка по заводскому номеру;
* просмотр подробной информации;
* добавление нового ТО.

### Рекламации

Раздел содержит информацию об отказах и их устранении.

Предусмотрены:

* фильтрация по узлу отказа;
* фильтрация по способу восстановления;
* фильтрация по сервисной компании;
* сортировка по дате отказа;
* просмотр подробной информации;
* добавление новой рекламации.

## Пользовательские роли

В системе предусмотрены следующие роли:

* **Клиент**
* **Менеджер**
* **Сервисная организация**
* **Неавторизованный пользователь**

Доступ к отдельным разделам и операциям зависит от роли пользователя.

## Тестовые данные

В предоставленном дампе базы данных находятся данные для проверки основных функций приложения:

* пользователи;
* техника;
* справочники;
* техническое обслуживание;
* рекламации;
* сервисные организации.

Для проверки работы системы рекомендуется сначала восстановить `silant_dump.sql`, а затем запустить проект.

## Важное замечание

Файл `silant_dump.sql` содержит готовое состояние базы данных для проверки проекта.

Если база данных уже восстановлена из дампа, удалять её или создавать заново перед запуском Django не требуется.
